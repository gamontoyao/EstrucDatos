01

Tipos de datos

Antes de usar una variable hay que declararla: decirle a C++ qué tipo de dato va a guardar. Estos son los tipos básicos que vas a usar todo el tiempo.

Tip — usa float o double para decimales; double es el más usado por defecto porque guarda más precisión.
02

Asignación de variables

Asignar es darle un valor a una variable ya declarada, usando =. Puedes hacerlo en el mismo momento de declarar, o después.

// declarar y asignar por separado

// declarar y asignar en la misma línea (lo más común)

Ojo — char usa comillas simples 'A', mientras que string usa comillas dobles "Ana". Confundirlas es un error muy común.
03

Constantes y conversión de tipos

Una constante es una variable cuyo valor no puede cambiar una vez asignado. El casting convierte un valor de un tipo a otro.

Tip — si divides dos int sin convertir, C++ hace división entera y descarta el decimal: 5 / 2 da 2, no 2.5.

05

Condicionales (if / else)

Permiten que el programa tome decisiones: ejecutar un bloque de código u otro dependiendo de si una condición es verdadera o falsa.

Tip — else if es opcional y puedes encadenar varios; el else final se ejecuta solo si ninguna condición anterior fue verdadera.
06

Vectores y matrices

En C++ básico, la forma más práctica de manejar arreglos es con vector (de la librería <vector>): a diferencia de los arrays clásicos, pueden crecer y sabes su tamaño fácilmente.

// una matriz es simplemente un vector de vectores

Tip — las posiciones siempre empiezan en 0. El primer elemento de un vector es v[0], no v[1].

Estructuras de control

Sirven para repetir o decidir qué código se ejecuta. Las más usadas en programación estructurada son for, while y do-while.

// for: cuando ya sabes cuántas veces repetir

// while: repite mientras la condición sea verdadera

// break y continue controlan el flujo dentro del ciclo

Tip — el break dentro del switch es obligatorio si no quieres que la ejecución "caiga" al siguiente case. El switch no reemplaza al if/else cuando necesitas rangos o condiciones complejas.
08

Imprimir en consola

Se hace con cout y el operador <<. Puedes imprimir texto fijo, variables, o combinar ambos en una sola línea.

Tip — endl pasa a una nueva línea. Puedes encadenar tantos << como necesites en una sola instrucción.
09

Leer datos del usuario (cin)

Así como cout imprime, cin lee lo que el usuario escribe en consola y lo guarda en una variable.

// para leer una línea completa (con espacios) se usa getline

Tip — si mezclas cin >> con getline, casi siempre necesitas un cin.ignore() en el medio, o getline se "salta" leyendo una línea vacía.
10

Funciones

Una función agrupa código para reutilizarlo. La diferencia clave está en si devuelve un valor o no.

// void: ejecuta una acción, no entrega ningún valor

// con return: calcula y devuelve un valor

Diferencia clave — una función void se usa cuando solo quieres hacer algo (imprimir, modificar, mostrar). Una función con return se usa cuando necesitas el resultado para guardarlo o usarlo después en otra parte del código.

// ambas se escriben en el mismo .cpp, antes o después de main, y se llaman por su nombre

11

La función main

Todo programa en C++ necesita una función main(). Es el punto de entrada: cuando ejecutas el programa, la ejecución empieza ahí y termina ahí, sin importar en qué orden estén escritas las demás funciones en el archivo.

Tip — las funciones que main necesita se pueden definir antes o después de ella en el mismo archivo, pero deben existir en algún lugar del .cpp para que el compilador las reconozca.
